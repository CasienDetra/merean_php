# Microservice vs Monolith vs 3 tier Architecture
- client (web,mobile,pc)
- API Gateway 
- identify provider : authentication and authorization

| Feature     | Monolith              | Microservices             |
| ----------- | --------------------- | ------------------------- |
| Deploy      | Single unit           | Multiple services         |
| Scale       | Hard                  | Easy                      |
| Maintenance | Complex               | Easy                      |
| Tech Stack  | Single lang/framework | Multiple langs/frameworks |
